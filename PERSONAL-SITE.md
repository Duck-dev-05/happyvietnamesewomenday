# Personal gift website

The website shows a photo slideshow, background music, and one shared wish for everyone. Edit app/data/shared-wish.json to change the recipient heading, wish and closing, then redeploy. PNG downloads use this same message. Sharing copies only the website link.

Public wish submissions are disabled. Old individual cards are no longer displayed; existing Supabase records and the previous personal-wishes.json file are preserved.

Photos use app/data/photo-library.json. Music uses app/data/tracks.ts; audible playback may require the visitor's first interaction under browser autoplay rules.
